# FamilyIQ 2.1 — Premium Depth

This release makes the free local-first product visually wider, more premium and deeper without adding paid infrastructure.

## Wider
- five focused product tabs: Home, Timeline, Projects, Family and Profile
- real local counts, events, projects, memories and traditions
- Family Graph, Trust Center, project progress and profile metrics

## More premium
- cinematic gradient Family Brief
- stronger spacing, hierarchy, surfaces and rounded geometry
- feature story, insight cards, polished metrics and premium empty states
- upgraded bottom navigation and creation flow

## Deeper
- explainable offline recommendations
- projects linked to next actions
- family privacy and child-safety principles visible in product UI
- local records remain the source of truth
- swipe-to-delete remains soft deletion for future sync

## Cost boundary
No Supabase instance, OpenAI key, cloud media provider or paid notification service is required.

## Honest limitations
- project progress is currently deterministic demo logic rather than persisted milestones
- photos and music are not persisted yet
- offline intelligence is rules-based, not a language model
- full localization migration remains incomplete
- CI and physical-device validation must still pass before release
