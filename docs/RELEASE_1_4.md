# FamilyIQ 1.4 — Living Dashboard

Version 1.4 upgrades the first structured MVP into a more polished, premium family product surface.

## Product changes

- redesigned Home with a premium Family Brief hero
- expanded Family Pulse and daily recommendations
- richer projects with visible progress and next actions
- upgraded Timeline with filters, featured memories and AI Story cards
- redesigned Family Brain with AI orb, prompt chips and improved chat composer
- expanded Family area with graph, calendar events and Trust Center
- upgraded Profile with progress statistics and settings sections
- redesigned creation sheet with quick actions
- improved spacing, hierarchy, gradients, rounded surfaces and dark-theme compatibility

## Current product boundary

This release focuses on product experience and Flutter UI architecture. The data shown is local demo content. Production authentication, cloud persistence, media upload, notifications and real AI responses remain backend integrations.
